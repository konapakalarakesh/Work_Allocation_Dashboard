👥 Auditors & Process Mapping

Each row = an auditor tagged to a process with a capacity (HC) and a Priority (1–6). Auditors work Priority 1 first; if that process has 0 tickets, the engine falls through to Priority 2, then 3, and so on.

⏱️ Auditor AvailabilityDefault 480 min · editable per person

Minutes each auditor has today. Defaults to a full 480-min shift; edit for part-day, overtime, or short shifts. This directly caps how many tickets the engine gives them.

✅ Verifiers & Verification Mapping

Verifiers tagged per process, with the daily verification count. Edit count, change process, delete, or add. This drives the verification numbers in Daily Planning.

🧪 Verification AHTseconds → auto-converted to minutes

AHT for verifying a ticket, per process (some processes have more than one verification sub-type, e.g. MBO's Approval/RP/Count). Edit the seconds column — minutes updates automatically. This will drive verifier ticket-count allocation.

📥 Upload Worked/Resolved DumpVerifiers & sample %: set in Main

Upload the day's completed audits (columns: Task/Task_Name, Date, SIM_ID/Short ID, Auditor). The tool samples each auditor's work per the process sample %, assigns to your Main verifiers (verifier ≠ auditor), and produces one CSV per verifier per process with every sampled ticket in it. If a process has only one verifier and they also worked the ticket, it's flagged in its own file instead of being dropped.
